Este dataset é um "dump" dos dados de cada deputado federal na Câmara dos Deputados, reunidos em um único arquivo json.
A API da Câmara (https://dadosabertos.camara.leg.br) já disponibiliza em API Rest, mas não um dump direto desses dados, o que dificulta a ingestão em massa.
O que esse dataset faz é basicamente facilitar isso ao fazer a parte suja de obter deputados um por um na API e reunir em um arquivo para download, sem fazer nenhuma alteração nos dados originais.

A lista de deputados vem dos Dados Abertos atuais; os detalhes são obtidos em XML na API legada da Câmara, assim como na versão completa. A atualização incremental considera deputados da legislatura atual e da anterior, com até 256 downloads por execução e validade de três dias para o cache. O JSON consolidado também mantém os dados históricos disponíveis no cache local.
